# 기본 FMCW LiDAR — v2 계측 구성

2026-09-22, `codex/fmcw-base` 작업 공간 기준.

이전 `FMCW_LiDAR_v2`의 계측·처리 기능을 유지하고 PCD 파일 재생과 모델 가중치 기능을 제외한 기본 제품이다.

| 기능 | 기본 제품 |
|---|---|
| Alazar ATS 계측 / MCU / EDFA 제어 | 유지 |
| CPU FFTW / CUDA cuFFT | 둘 다 포함 |
| Time / FFT / Peak / Distance·Velocity / B-scan / Live 3D | 유지 |
| RAW·처리 결과 저장 / RAW 재생 / UDP 전송 | 유지 |
| PCD·XYZ·pointcloud 파일 열기와 재생 | 제외 |
| Weight 선택 / CenterPoint 추론 / 탐지 결과 표시 | 제외 |

## 실행

프로젝트 루트의 `RUN.cmd` 또는 `build/package/Windows-Basic/FMCW_LiDAR.exe`를 실행한다.
시작 화면은 Overview이며 계측 페이지 8개와 Live View의 6개 탭을 유지한다.
기존 v2처럼 시작 설정은 Simulator / FFTW이며, 실제 장비와 GPU 사용은 Digitizer·Processing에서 선택한다.

현재 패키지는 Alazar ATS, FFTW, CUDA FFT를 포함한다. cuDNN과 모델 가중치는 필요하지 않다.
PCD 파일 재생은 PCDReplay 작업 공간, 객체 탐지는 CenterPoint 작업 공간에서 진행한다.

## 빌드 범위

- `windows-base`: Alazar SDK·FFTW·CUDA Toolkit 필수. `build/preset-windows-base`에 생성한다.
- `windows-base-cpu`: SDK/GPU 없는 개발용. Simulator·RAW 재생·FFTW를 지원하며 `build/preset-windows-base-cpu`에 생성한다.
- 기본 앱의 CMake에서 CenterPoint·cuDNN 연결을 제거했다. `FMCW_WITH_CENTERPOINT=ON`은 오류로 거부한다.
- `tests/support/point_cloud_replay/`의 PCD 파일 reader는 테스트용 `fmcw_replay_test_support`에만 연결한다. 기본 앱과 `fmcw_core`에는 연결하지 않는다.
- 테스트에서 기존 reader를 사용하는 이유는 저장 포맷과 렌더링 회귀 검증을 유지하기 위해서다.

SDK 경로와 명령은 [작업 공간 안내](../guides/workspaces_ko.md)를 따른다.
2026-09-22 파일 재배치 이후 소스 위치는 [역할별 소스 안내](../../src/README.md)를 따른다.
